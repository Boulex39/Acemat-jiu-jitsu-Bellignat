# Acemat Jiu-Jitsu Bellignat

Site vitrine du club, construit comme un projet d'apprentissage et publié avec Sites.

## Objectif

Présenter le club, ses disciplines, son planning, ses tarifs et l'adresse de la salle. La section contact sera complétée ultérieurement.

## Stack prévue

HTML, CSS et JavaScript natifs. Pas de framework pour cette première version : le site est principalement informatif et n'a pas besoin de serveur applicatif.
